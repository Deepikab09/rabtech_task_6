## 3. Connect the Task 05 model (required)

1. Open and run all cells in `Task_05_Deep_Learning_NLP_Text_Classifier.ipynb`.
2. The final notebook cell saves `imdb_sentiment_classifier.keras`.
3. Create a folder named `models` inside this Task 06 project.
4. Copy `imdb_sentiment_classifier.keras` into `models/`.
5. Keep the model produced by Task 05; do not replace it with a newly trained unrelated model.

The service uses the same IMDB word index, vocabulary limit (10,000), token encoding, and sequence length (250) as Task 05.

## 4. Run locally

Use Python 3.11 in a virtual environment.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/docs` for interactive Swagger API documentation.

## 5. API endpoints

### `GET /`
Returns service information and documentation paths.

### `GET /health`
Returns service status and whether the model file is present.

### `POST /predict`
Request:

```json
{
  "text": "The movie was wonderful and the acting was brilliant."
}
```

Example response (illustrative format; probabilities are produced by the trained model):

```json
{
  "label": "Positive",
  "confidence": 0.91,
  "positive_probability": 0.91
}
```

`label` is `Positive` when positive probability is at least 0.5; otherwise it is `Negative`. `confidence` is the probability associated with the predicted label.

## 6. Run tests

```bash
pytest -q
```

The automated tests cover the root and health endpoints, successful positive/negative response schemas, missing or blank text validation, and unsupported HTTP methods. Inference is mocked in unit tests so the tests do not need to download TensorFlow model assets.

## 7. Docker

Build the image from the project root after adding the trained model:

```bash
docker build -t task06-sentiment-api .
```

Run the container:

```bash
docker run --rm -p 8000:8000 task06-sentiment-api
```

Then open `http://localhost:8000/docs`.

## 8. Architecture

```text
Client
  |
  | POST /predict { "text": "..." }
  v
FastAPI request validation (Pydantic)
  |
  v
Text preprocessing
  |  lowercase/tokenize
  |  IMDB word-index encoding
  |  pad/truncate to 250 tokens
  v
Task 05 TensorFlow/Keras model
  |
  v
Prediction post-processing
  |  Positive / Negative
  |  confidence + positive probability
  v
JSON response
```

## 9. Error handling

- `200 OK`: prediction completed.
- `422 Unprocessable Entity`: missing, blank, or invalid request text.
- `503 Service Unavailable`: trained model file or required model assets are unavailable.
- `500 Internal Server Error`: inference fails after artifacts load.
